Tiêu đề

Đăng hoặc hẹn Facebook thành công thì file rời khỏi kho, chuyển vào folder này. Cùng ổ = đổi chỗ file. Khác ổ = chép rồi xóa nguồn. Để trống thì chuyển vào thư mục con da-dang cạnh file.

Có chữ dán thì dùng chữ dán. Để trống thì lấy file. Bài chữ cần ít nhất tiêu đề, mở đầu hoặc link đăng.

Bài ra dạng: câu mở đầu, xuống dòng link đăng, rồi tiêu đề. Link này không lấy từ kho comment.

Chỉ gửi khi loại bài là video. Phần mô tả vẫn là mở đầu + link đăng + tiêu đề đầy đủ.

0 = mọi bài đều comment. Lần lượt lấy bài sớm nhất trong ngày. Random lấy đúng số đó. Link comment có URL thì gửi kèm thẻ link, Facebook từ chối thì gửi chữ.

Đăng ngay API

Gọi Facebook ngay. Cùng một token cách nhau 30 giây. Token khác chạy song song. Dùng tiêu đề, mở đầu và link đăng ở trên.

Hẹn giờ hàng loạt

0 = đúng giờ đã viết. Lớn hơn 0 = bài sau cùng page cách bài trước ít nhất khoảng đó.

Facebook nhận lịch từ 10 phút đến 180 ngày. Job xong thì tắt app được. Mỗi page một bộ mốc.

Hẹn theo ngày

Điền số ngày và số bài mỗi ngày.

Ngày 2, 3… lặp cùng giờ rồi cộng khoảng cách. Nhiều bài một ngày cách nhau ít nhất 1 phút. Hẹn Facebook, job xong thì tắt app được.

Đăng trực tiếp

App đợi đến giờ rồi mới gọi Facebook. Giờ đã qua thì đăng ngay. Máy và app phải bật đến khi job xong. 0 phút = comment ngay sau bài.
